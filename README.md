# spam-email-prediction
A full-stack Spam Email Detection Web App built using Machine Learning and Flask. Users can input an email message and instantly receive a prediction — whether the message is Spam or Not Spam.


# Features

Train a Multinomial Naive Bayes classifier to detect spam messages.

Text preprocessing and feature extraction using CountVectorizer.

Clean and responsive frontend built with HTML and CSS.

Flask backend for handling user input and serving predictions.

Real-time predictions without refreshing the page.

# How It Works

1.    User enters an email message.

2.    The message is vectorized using the trained vocabulary.

3.    The ML model predicts Spam / Not Spam.

4.    Result is instantly displayed on the webpage.
